# Hands-On Artificial Intelligence for IoT – Code và báo cáo

Code đi kèm sách *Hands-On Artificial Intelligence for IoT* (Amita Kapoor, Packt Publishing, 2019), dùng cho bài tập lớn môn học.

## Nội dung repo

| Thư mục / file | Nội dung |
|---|---|
| `Chapter01` – `Chapter12` | Notebook, script và dữ liệu mẫu theo từng chương của sách (giữ nguyên bản gốc) |
| `Hardware Software list.pdf` | Danh sách phần mềm cần cho từng chương |

## Chương 11 – AI for Smart Cities IoT

| File | Nội dung |
|---|---|
| [Báo cáo nội dung Chương 11](Chapter11/Bao_cao_noi_dung_Chuong_11.md) | Tóm tắt chi tiết toàn bộ chương, nhận xét, các lỗi của sách, bảng thuật ngữ |
| [Báo cáo chạy code Chương 11](Chapter11/Bao_cao_chay_code_Chuong_11.md) | Môi trường, các bước chạy, kết quả, đối chiếu với sách, phân tích |
| [SF_crime_category_detection.ipynb](Chapter11/SF_crime_category_detection.ipynb) | Notebook gốc của tác giả |
| [SF_crime_category_detection_spark4.ipynb](Chapter11/SF_crime_category_detection_spark4.ipynb) | Notebook đã chạy lại bằng Python 3.12, PySpark 4.2.0, Java 21 |

**Dữ liệu:** các file CSV của Chương 11 không có trong repo vì vượt giới hạn 100 MB/file của GitHub. Tải bộ *San Francisco Crime Classification* tại <https://www.kaggle.com/c/sf-crime/data>, đặt `train.csv` vào `Chapter11/` rồi sao chép thành `sf_crime_dataset.csv`.
